Machine learning

Spotify Genre Classification

Compared classifiers for predicting song genre from Spotify track attributes.

Pythonscikit-learnJupyter
GitHub →
Read case study

Question

Can song attributes help classify a track’s genre?

Approach

The notebook compares scaled Logistic Regression, Decision Tree, Random Forest and hard-voting classifiers using a 20% random holdout.

Notebook-reported results

  • Logistic Regression and hard voting: 43.96% holdout accuracy.
  • Decision Tree: 42.86%; Random Forest: 41.76%.
  • A separate Kaggle score of 0.375 is reported; it is not directly comparable to holdout accuracy.

Validation note: The repository README describes popularity prediction, while the notebook performs genre classification. The source CSVs are not included, so these results have not been independently reproduced.

GitHub →
Read case study

Question

How well can recurrent models classify airline tweets as positive, neutral or negative?

Approach

The notebook explores cleaned and uncleaned text with LSTM and self-attention variants, alongside GRU, RNN and transfer-learning experiments.

Notebook-reported results

Selected LSTM/attention runs report 77.49–79.64% test accuracy on an 80/20 split; a GRU section reports 80.70%.

Validation note: A later RNN section reports 10% accuracy and warns that some classes receive no predictions. Results across sections are not a controlled model ranking. The Kaggle dataset is not included; reproducing the runs requires dataset access.

Spotify Popularity Regression

Compared regression models for predicting a track’s popularity from its song attributes.

PythonRegressionRMSE
GitHub →
Read case study

Question

How accurately can track popularity be estimated from Spotify song attributes?

Approach

The notebook compares Linear Regression, Decision Tree, Random Forest and Gradient Boosting, reporting root mean squared error (RMSE).

Notebook-reported results

  • Linear Regression: RMSE 9.7084.
  • Random Forest: RMSE 9.1049.
  • Gradient Boosting: RMSE 9.0878.
  • Decision Tree: RMSE 13.7250.

Validation note: The SVR implementation fits on the full dataset rather than the training split, so it is excluded from this comparison. The input CSVs are not included, so results have not been independently reproduced.
