Privacy

Simple website privacy information.

This page describes what happens when you use this personal portfolio. It is intentionally limited to the services actually used by the site.

Forms

Contact messages

The contact form is a static client-side form. It does not submit your information to a database. It prepares an email draft using your device's default mail application.

Local storage

Theme preference

The site stores a small theme preference in your browser's localStorage so dark/light mode persists. No account is required.

Hosting

GitHub Pages

When hosted on GitHub Pages, standard hosting infrastructure may process technical request information such as IP address and browser metadata. Refer to GitHub's current privacy documentation for details.
